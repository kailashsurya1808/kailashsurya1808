# Contributing to My Learning Repository 🤝

This repository is mainly for my personal learning and practice.

## How I Work

1. Learn a concept.
2. Practice it with small examples.
3. Build a project.
4. Test the project.
5. Review the code.
6. Improve it.
7. Document what I learned.

## Code Quality

I will try to:

- Use clear variable names.
- Keep code simple and readable.
- Add comments when they are useful.
- Test my programs.
- Fix mistakes instead of ignoring them.

I want to understand the code I write rather than simply copying solutions.

## Goal

Build practical skills through consistent practice and projects.
