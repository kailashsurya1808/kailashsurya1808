# Git Commits 📝

A commit records a set of changes in a Git repository.

## Check Changes

git status

## Add Changes

git add .

## Create a Commit

git commit -m "Describe my changes"

## View Commit History

git log

## View Short History

git log --oneline

## Good Commit Messages

Good:

git commit -m "Add number guessing game"

Avoid:

git commit -m "stuff"

## My Practice

I will make small, meaningful commits so that my project history clearly shows what I have learned and changed.

## Goal

Understand that commits are checkpoints in my project's history.
