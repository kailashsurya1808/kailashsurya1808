# Git Commands I Am Learning 🔀

## Check Git Version

git --version

## Start a Repository

git init

## Check Repository Status

git status

## Add Files

git add .

## Create a Commit

git commit -m "My first commit"

## View Commit History

git log

## Connect to GitHub

git remote add origin <repository-url>

## Push Changes

git push origin main

## Pull Changes

git pull origin main

## My Goal

Understand what each command does instead of simply memorizing commands.
