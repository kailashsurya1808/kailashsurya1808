# GitHub Workflow 🔄

This is the workflow I will use when working on projects.

## 1. Create or Open a Repository

Start with a GitHub repository for the project.

## 2. Make Changes

Write code, update documentation, or improve the project.

## 3. Check Changes

git status

## 4. Stage Changes

git add .

## 5. Commit Changes

git commit -m "Describe the change"

## 6. Push to GitHub

git push origin main

## 7. Review

Check the repository on GitHub and make sure the changes are correct.

## 8. Improve

Find problems, fix them, and make another meaningful commit.

## My Workflow

Learn → Practice → Build → Commit → Review → Improve
