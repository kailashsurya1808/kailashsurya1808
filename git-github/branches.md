# Git Branches 🌿

Branches allow me to work on changes without directly changing the main branch.

## Create a Branch

git branch feature-name

## Switch to a Branch

git switch feature-name

## Create and Switch to a New Branch

git switch -c feature-name

## See All Branches

git branch

## Switch Back to Main

git switch main

## Merge a Branch

git switch main
git merge feature-name

## Delete a Branch

git branch -d feature-name

## Practice Goal

I want to learn how branches are created, used, merged, and deleted.
