# Number Guessing Game 🎯

A beginner-friendly Python game where the computer chooses a random number and the player tries to guess it.

## Concepts Learned

- Variables
- User input
- `if`, `elif`, and `else`
- `while` loops
- Counters
- The `random` module
- Basic problem solving

## How It Works

1. The computer chooses a number between 1 and 100.
2. The player enters a guess.
3. The program says whether the guess is too high or too low.
4. The player continues until the correct number is guessed.
5. The program counts the number of attempts.

## What I Learned

This project helped me understand how different Python concepts can work together to create a simple interactive program.
