# Problem-Solving Practice 🧩

This file contains problems I will solve while improving my programming and logical thinking.

## Beginner Problems

### 1. Even or Odd
Write a program that checks whether a number is even or odd.

### 2. Largest of Three Numbers
Write a program that finds the largest of three numbers.

### 3. Sum of Numbers
Find the sum of numbers from 1 to N.

### 4. Reverse a Number
Write a program that reverses the digits of a number.

### 5. Factorial
Write a program to calculate the factorial of a number.

## Intermediate Problems

### 6. Prime Number
Check whether a number is prime.

### 7. Fibonacci Series
Generate the first N Fibonacci numbers.

### 8. Palindrome
Check whether a word or number is a palindrome.

### 9. Find Duplicates
Find duplicate values in a list.

### 10. Frequency Counter
Count how many times each value appears in a list.

## My Rule

Before looking at a solution:

1. Understand the problem.
2. Break it into smaller steps.
3. Write an algorithm.
4. Try the solution myself.
5. Test it with different inputs.
6. Review and improve the code.

## Goal

Become better at solving problems independently rather than memorizing solutions.
